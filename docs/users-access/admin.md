# Yana Admin

The Yana team needs **control of quality, money and disputes**. The admin area gives them that, so they can run the whole operation with confidence.

---

## Capabilities

| Area | Capabilities |
|---|---|
| **Quality** | Verify properties before they go live and award a verification badge |
| **Customers & properties** | Manage customers and properties |
| **Bookings & money** | Manage bookings, payments, refunds and disputes |
| **Promotions** | Run platform-wide promotions |
| **Reporting** | Read reports |
| **Wallet** | Oversee the wallet and group savings ("Stokvel") area |
| **AI assistant** | Oversee the AI travel assistant (later phase) |

---

## Success Criterion

The team can run the whole operation (money, quality and support) from the admin area with confidence. See [Success Metrics](../metrics.md).
