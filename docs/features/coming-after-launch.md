# Coming After Launch

Phase 1 is the Yana core. These features widen the ecosystem once that core journey is stable. See [Phases](../phases.md).

---

## Phase 2 · Expand — Planning + discovery

| Feature | Description |
|---|---|
| **AI travel assistant** | Guided planning with user memory and preferences, learning from its user across future trips and interactions |
| **Flights** | A Skyscanner-style comparison flow, linking out to the airline or agent |
| **Deeper activity inventory** | A wider catalogue of things to do |
| **Smarter destination recommendations** | Better-matched suggestions of where to go next |

---

## Phase 3 · Grow — Broader travel ecosystem

| Feature | Description |
|---|---|
| **Car hire** | Rent a car as part of the trip |
| **Cruises** | Inspired by Scoopon AU |
| **Gift cards** | Inspired by Scoopon AU |
| **Homes and apartments** | A wider range of places to stay |
| **More markets** | Additional markets, currencies and languages |
| **Buy now, choose dates later** | Once partner and legal mechanics are confirmed: needs clear inventory, expiry and refund rules |

## Merchandising

Destination-based and retargeted promotions are wanted, but should feel **editorial and relevant** and never make the interface feel like a discount marketplace.
