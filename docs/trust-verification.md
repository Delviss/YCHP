# Property Verification

Trust is central for travellers booking a trip for the first time. Every property on Yana is **verified by the Yana team before it goes live**.

---

## How It Works

```mermaid
flowchart LR
    A[Owner lists property] --> B[Yana team reviews]
    B -->|Approved| C[Live with Verified badge]
    B -->|Needs changes| A
```

| Step | What happens |
|---|---|
| **Listing** | The owner creates an account and lists the property with photos, rooms and prices |
| **Verification** | The Yana team verifies the property from the admin area |
| **Badge** | Verified properties are awarded a **verification badge** |

---

## The Verified Badge

Badges such as **"Verified"** and **"Curated Pick"** use the brand's blue as an accent, never a wash. See [Colour Palette](brand/colour.md).

---

## Disputes

The Yana team manages disputes and helps resolve issues from the [admin area](users-access/admin.md).
